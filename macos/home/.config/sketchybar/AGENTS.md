# О данной директории
Данная директории в данной директории находятся конфиг и плагины SketchyBar.
SketchyBar используется в связке с Aerospace, конфиг которого располагается в `~/.aerospace.toml`
Данная директория не является git-репозиторием и не требует работы с git.

## Задачи
При выполнении задачи придерживайся плана:
1. Провести анализ.
2. При необходимости задать уточняющие вопросы, если что-то непонятно.
3. Написать план точечных правок и дать на подтверждение.
4. После внесения правок выполнить команду `brew services restart sketchybar` для применения изменений.

## Команды
- Не считай команду `brew services restart sketchybar` успешно завершённой, пока не увидишь в выводе `Successfully stopped` и `Successfully started`. Команда может висеть до 5 минут с выводом "Stopping `sketchybar`... (might take a while)" - это нормально.
