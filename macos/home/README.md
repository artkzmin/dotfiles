# Раскладка
Для смены сочетаний клавиш используется [Karabiner](https://karabiner-elements.pqrs.org).
Убрать появление индикатора языка возле курсора при переключении языка можно командой:
```bash
defaults write kCFPreferencesAnyApplication TSMLanguageIndicatorEnabled -bool false
```

## Скриншоты
Аналог `Win + Shift + S` на Windows можно настроить в системных настройках:
В `Клавиатура - Сочетания клавиш - Снимки экрана` поменять местами (переопределить) `⌘ + ⇧ + 4` и `⌘ + ⌥ + ⇧ + 4`.
